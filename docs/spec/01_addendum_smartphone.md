# 原文：追加指示（スマートフォン対応）

Claudeへの追加指示：スマートフォン対応
先ほどの「はにわと土偶のエンドレス仕分けゲーム」の要件を変更します。

1. 対応プラットフォーム【確定】
PCとスマートフォンの両方で遊べるブラウザゲームとします。

* Windows / macOS：Chrome、Edge、Safariなど
* Android：Chromeなど
* iPhone：Safariなど
* アプリのインストール不要
* 縦画面・横画面への対応を考慮
* 画面サイズに応じてUIを自動調整するレスポンシブデザイン
* タッチ操作とキーボード操作の両方に対応

2. 操作方法
PC

* A / ←：はにわ
* D / →：土偶
* Space：一時停止

スマートフォン

* 画面左側のボタン：はにわ
* 画面右側のボタン：土偶
* 画面上部の一時停止ボタン

スマホでは片手・両手のどちらでも操作しやすいボタン配置としてください。
タップした瞬間に入力を判定し、ボタンを押し続けても連続入力されない仕様とします。
タッチ操作時は、誤操作を防ぐため、ゲーム画面のスクロールやダブルタップによる拡大を適切に制御してください。

3. スマホ画面
縦画面を基本レイアウトとします。
上部：スコア・コンボ・ミス回数
中央：縦方向に流れるコンベアと出土品
下部：大きな「はにわ」「土偶」仕分けボタン
スマートフォンでも出土品の見た目を判別しやすい表示サイズを確保してください。

4. パフォーマンス

* 60fpsを目標とする。
* 画面サイズに応じて描画負荷を調整する。
* ゲームロジックをフレームレートから独立させる。
* 画面が非表示になった場合は自動的に一時停止する。
* タッチ操作による入力遅延を可能な限り抑える。
* PCとスマホで判定条件が不公平にならないようにする。

5. 技術選定
HTML5、CSS、TypeScriptを基本候補とし、Canvasまたはゲーム向けライブラリの採用を検討してください。
特に以下を重視します。

* PC・スマホ両対応
* 軽量で高速
* ブラウザだけで実行可能
* 将来的にWebサイトとして公開できる
* ゲームの更新・保守が容易

適切な技術構成を比較し、推奨案を提示してください。

6. 既存仕様との関係
これまで確定したエンドレス型、コンベア型、先行入力許可、左右仕分け、コンボ、ミス判定の仕様は維持します。
スマホ対応によって変更が必要になる部分は、変更理由と選択肢を提示し、承認を得てください。
まだ実装は開始せず、まず要件定義書を更新してください。
