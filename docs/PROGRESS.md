- 開発サーバー：`npm run dev`（このセッションでは `.claude/launch.json` の `game`。5173が使用中だと別ポート）

- git：ブランチ `main`、リモート origin = GitHub（公開）。リポジトリ内の user.name=y5268。**main に push すると自動で本番公開される。公開中のゲームには遊んでいる人がいるので、push（リリース）はユーザーが時期を決める**

- 止めるとき：wrangler は子プロセス（workerd.exe）が残ることがある。残ったらタスクマネージャーか `taskkill /T /F /PID <cmd.exe のPID>` で止める。
- ローカルのデータベースは `server/.wrangler/` にある（git に入れない）。確認時のテスト用の記録（テスト31〜32など）が入っている。
